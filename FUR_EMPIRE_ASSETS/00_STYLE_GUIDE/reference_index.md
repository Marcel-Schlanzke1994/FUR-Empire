# Referenzen und Herkunft

| Quelle | Verwendung |
| --- | --- |
| `a_highly_detailed_cinematic_game_asset_pack_overv.png` | Alpine Kolonie, Gold-Cyan-Gliederung, Grundcharakter von Terra und Orbit |
| `a_highly_detailed_extensive_game_asset_sheet_co.png` | Kompakte Fahrzeug- und Gebäudemassen, Segmente, Fassaden und Beleuchtung |
| `a_large_highly_detailed_game_asset_concept_sheet.png` | Lesbarkeit von Symbolen, Kommandantenuniform, Materialien und Gestaltung der Schiffsklassen |
| `PRODUCTION MASTER PROMPT.md` und eingefügter Produktionsauftrag | Dateikennungen, Größen, Formate, Motive und Designregeln |
| `static/assets/goods/*.svg` | Die zehn vorhandenen FUR-Ressourcen-Symbole als semantische Ausgangsbasis für das neu gezeichnete Set |
| `static/style.css` und `static/app.js` | Quadratisches Terra-Kartenraster und Kartenkontext |
| `docs/game-design/FUR_EMPIRE_SPEC.md` und `docs/SPIELANLEITUNG.md` | Bestehende Genesis-Direktiven als Grundlage für die Kampagnenszenen |

Die Konzepttafeln wurden für die Art Direction und zum Abgleich herangezogen. Die ausgelieferten Motive wurden als neue Einzelgrafiken erstellt. Der Wortmarken-Schriftzug besteht aus eigens gezeichneten Vektorpfaden. Vorschautafeln verwenden auf dem Produktionsrechner vorhandene Segoe UI, und die SVG-Silhouettenstudien verwenden die generische Familie `sans-serif`. Die Pakete enthalten keine Schriftdateien.
